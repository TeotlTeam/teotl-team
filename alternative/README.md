# Teotl Team

Sitio estático bilingüe en preparación, listo para ejecutar localmente o desplegar en GitHub Pages.

## Abrir localmente

Abre `index.html` en un navegador. No requiere instalación ni compilación.

## Antes de publicar

1. Sustituye los archivos en `assets/` por el logo final, fotografías de playeras, entrenamiento y una foto de Enrique. Conserva los mismos nombres o actualiza las rutas en `index.html`.
2. Cuando compres el dominio, reemplaza `https://teotlteam.com` en `robots.txt` y `sitemap.xml` por el dominio final.
3. Revisa los textos legales con asesoría adecuada antes de usar el sitio comercialmente.

## GitHub Pages

Sube el contenido de esta carpeta a un repositorio. En Settings → Pages, elige publicar desde la rama `main` y la carpeta `/(root)`.
